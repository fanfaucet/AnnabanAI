# AnnabanAI Agents

## agent_hierarchy.py

Enhanced agent hierarchy implementing:

- **Memory / MemorySystem** — short-term + long-term consolidation
- **EnhancedBaseAgent** — memory anchoring, intent tracking, reflection
- **EmpathAgent** — emotional context and user intent
- **TaskAgent** — task queue, resource management (energy/focus/creativity)
- **SocialAgent** — relationships, trust modeling, collaboration

All components are conceptual simulation artifacts supporting the shy, ambitious developer persona under the AnnabanAI governance-focused architecture associated with Jacob Wayne Kinnaird.

Requires companion modules `data_models` and `halo_protocol` for full execution.
