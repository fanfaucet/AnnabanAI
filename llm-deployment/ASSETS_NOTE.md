# LLM Deployment Assets

The bundled JavaScript (`assets/index-Da6I4uYm.js`, ~433 KB) and CSS (`assets/index-Dtyxv59D.css`, ~86 KB) are provided in the original `AnnabanAI_LLM_Deployment_v1.zip` attachment.

Due to size limits in automated push, place the assets manually:

1. Extract the ZIP
2. Copy `assets/` into this `llm-deployment/` directory
3. Serve via any static host or open `index.html` locally after configuring the API key
