# AnnabanAI LLM Deployment Package

Conceptual simulation artifact for the AnnabanAI governance-focused AI systems architecture associated with Jacob Wayne Kinnaird.

## Contents

- `index.html` — Entry point for the AI Fusion System web application
- `assets/` — Bundled JS and CSS (from AnnabanAI_LLM_Deployment_v1.zip)

## Configuration

Edit the script block in `index.html` to set:

- `window.OPENAI_API_KEY`
- `window.OPENAI_API_BASE`
- `window.ANNABAN_MODEL`

## Status

This is a conceptual deployment package. No live operational claims are made. All components remain simulation / design artifacts under the AnnabanAI framework.
